# Serduszka Emote (Forge 1.20.1)

Zapętlona animacja "zakochanej" postaci z sercami nad głową, włączana klawiszem **G** (do zmiany w Opcje → Sterowanie).

- Animacja: `src/main/resources/assets/serduszka/emotes/love.json` (klatki kluczowe, stopnie i piksele modelu).
- `tools/gen.py` generuje ten plik, `tools/preview.py` rysuje podgląd póz bez uruchamiania gry.
- Gotowy plik `.jar` budowany jest przez GitHub Actions i trafia do folderu `dist/` na tej gałęzi.
